# 版本更新

## v1.14.0

- 普通步耗温改为落子方的纯棋型分，邻近、经验与攻防加分仍参与候选排序和路线权重，不再额外降低耗温；普通耗温系数为200，根最低三手只豁免温度停止，仍实际扣温。
- 五档动态攻防统一作用于根层与递归普通候选，最多4点：0攻4防、1攻3防、2攻2防、3攻1防、4攻0防。主动新增威胁推进档位，黑白视角互补，模拟状态回滚，候选和缓存身份包含档位上下文。
- 跨回合旧叶子按当前根距离拨温：`64 × 2^(-深度/4)`，抵扣原欠温；同一轮不重复领温，已完成硬胜败直接复用。
- 非终局谱着、唯一候选和堵五统一进入搜索建树，真实落子后保留可复用子树；实际成五仍直接终局。
- 接入双方合计前5手的稀疏开局库，保存人工确认候选、暂定主着及有限教师评分来源；黑五按每组保底前三，其余普通分严格高于400或正杀棋标签保留。谱着固定根落点后继续搜索，出谱交回引擎，第6手起不回落到旧库接管。
- 桌面与Android统一使用旗舰默认，移除旧三档棋力及不再适用的耗时标签；同步Python引擎和开局数据。

本地对战显示当前配置具有较低的平均着手耗时，有限样本相对旧版出现改善；不将其表述为稳定提速倍数、官方Elo或已超过DDQK。温度不是单手硬时限，战术分批仍可能返回部分评分。三平台安装包以对应GitHub Release的实际构建结果为准。

## v1.13.0

- 普通候选统一为根层与内部固定4点、2攻2防；取消随深度收窄与根层动态配额差异。
- 战术搜索使用前8手免费、之后按2/4/8梯度耗温；每节点先展开3个战术候选，其余保留待展开信息，支持后续换根补推。部分评分明确标记，不冒充完整搜索。
- 区分开局冷启动160、中途冷启动120和续温信用160；协议及离线工具显式指定温度时同时覆盖三者。
- 修复近端防守候选，精筛无效防点；复合威胁优先取防守兼冲四点，否则取共同防点。空共同防点按当前候选政策结束分支。
- 已证明的硬胜败使用±1000并提前结束无用展开。状态仍只描述本次有限搜索范围，不是全盘穷举证明。
- 完善真实落子换根、旧叶子续推、冷算完整子树复用及缓存上下文隔离；完整盘面键按行打包，保持键内容一致。
- 新增逐层继承份额的贡献汇总报告，父节点保存子树汇总；该报告不替换正式选棋评分。正式评分回溯采用逐层归一加权。
- 棋谱复盘加入搜索树调试页，支持过程观察、录像导入导出及缓存阶段观察。
- 移除我方神经网络运行及训练接口，保留纯Python、纯算法正式路径；项目介绍和算法文档统一迁入docs。
- 修复离线记录器漏记战术静态探针的叶子参数依赖，以及显式实验温度未覆盖冷搜索的问题。

源码完成全量Python回归、Android引擎同步及Node桥接检查。Tk窗口创建、缩放及复盘入口完成程序化冒烟；搜索树深层交互未做完整人工视觉验收。三平台安装包以对应GitHub Release的实际构建结果为准，下载须核对同版本SHA256SUMS.txt。

搜索温度不构成单手硬时限，三点分批可能返回部分评分。已有小样本本地对战校准不构成官方等级分，也不证明相对旧版棋力不退步。
